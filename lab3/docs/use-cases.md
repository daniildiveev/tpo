# Прецеденты Использования

Дата фиксации поведения интерфейса: `2026-03-18`.

## Допущения

- Под "Twitter" в рамках варианта понимается актуальный публичный веб-интерфейс X.
- Рассматривается роль `Гость`.
- Тестируются только сценарии, доступные без входа в учетную запись.
- Элементы страницы создаются динамически, поэтому выбор выполняется XPath-локаторами по тексту и семантическим атрибутам.

## UC-01. Просмотр публичной landing page

- Актор: `Гость`
- Предусловие: сайт доступен по адресу `https://x.com/`
- Основной поток:
  1. Пользователь открывает главную страницу.
  2. Система показывает onboarding-блок `Happening now`.
  3. Система показывает варианты `Create account` и `Sign in`.
  4. Система показывает ссылки на правовые документы и справку.
- Постусловие: пользователь может выбрать вход, регистрацию или перейти к справочной информации.

## UC-02. Управление cookie banner

- Актор: `Гость`
- Предусловие: на landing page показан баннер cookie consent.
- Основной поток:
  1. Пользователь нажимает `Refuse non-essential cookies`.
  2. Система скрывает cookie banner.
  3. Остальная часть landing page остается доступной.
- Постусловие: пользователь продолжает работу без баннера.

## UC-03. Открытие формы входа

- Актор: `Гость`
- Предусловие: сайт доступен.
- Основной поток:
  1. Пользователь переходит на страницу входа.
  2. Система показывает заголовок `Sign in to X`.
  3. Система показывает поле `Phone, email, or username`.
  4. Система показывает действия `Next`, `Forgot password?`, `Sign up`.
- Постусловие: пользователь может начать авторизацию или перейти к смежным сценариям.

## UC-04. Переход к восстановлению пароля

- Актор: `Гость`
- Предусловие: открыта форма входа.
- Основной поток:
  1. Пользователь нажимает `Forgot password?`.
  2. Система открывает экран `Find your X account`.
  3. Система предлагает ввести email, телефон или username для продолжения.
- Постусловие: пользователь находится на первом шаге password reset flow.

## UC-05. Открытие формы регистрации

- Актор: `Гость`
- Предусловие: открыта landing page.
- Основной поток:
  1. Пользователь нажимает `Create account`.
  2. Система открывает модальное окно `Create your account`.
  3. Система показывает поля `Name`, `Phone`, `Date of birth`.
  4. Система показывает кнопку `Next`, изначально недоступную без заполнения обязательных полей.
- Постусловие: пользователь может начать регистрацию.

## UC-06. Переключение канала регистрации с телефона на email

- Актор: `Гость`
- Предусловие: открыта форма `Create your account`.
- Основной поток:
  1. Пользователь нажимает `Use email instead`.
  2. Система скрывает поле `Phone`.
  3. Система показывает поле `Email`.
- Постусловие: пользователь может продолжить регистрацию по email.

## UC-07. Авторизация в учетной записи

- Актор: `Гость`
- Предусловие: открыта форма входа `Sign in to X`, у пользователя есть валидные учетные данные.
- Основной поток:
  1. Пользователь вводит логин (email, телефон или username) в поле `Phone, email, or username`.
  2. Пользователь нажимает `Next`.
  3. Система показывает поле `Password`.
  4. Пользователь вводит пароль и нажимает `Log in`.
  5. Система выполняет переход на главную страницу ленты `Home`.
- Постусловие: пользователь авторизован, доступны сценарии для роли `Авторизованный пользователь`.
- Альтернативный поток: при неверных данных система показывает сообщение `Wrong password!` или `Could not find your account`, пользователь остается на форме.

## UC-08. Выход из учетной записи

- Актор: `Авторизованный пользователь`
- Предусловие: пользователь авторизован, открыт интерфейс с боковой навигацией.
- Основной поток:
  1. Пользователь нажимает на блок аккаунта в нижней части боковой панели.
  2. Система открывает popup со списком аккаунтов.
  3. Пользователь нажимает `Log out @username`.
  4. Система показывает диалог подтверждения `Log out of X?`.
  5. Пользователь подтверждает действие кнопкой `Log out`.
  6. Система завершает сессию и перенаправляет на landing page.
- Постусловие: сессия закрыта, доступны только публичные сценарии.

## UC-09. Просмотр ленты

- Актор: `Авторизованный пользователь`
- Предусловие: пользователь авторизован, открыта страница `/home`.
- Основной поток:
  1. Система показывает переключатель вкладок `For you` и `Following`.
  2. Система загружает список постов в хронологическом или ранжированном порядке.
  3. Пользователь прокручивает ленту вниз.
  4. Система подгружает следующие посты по мере скролла.
  5. Пользователь переключает вкладку `Following`.
  6. Система показывает посты только от подписок.
- Постусловие: пользователь ознакомился с актуальным контентом ленты.

## UC-10. Переход к отдельному посту

- Актор: `Авторизованный пользователь`
- Предусловие: открыта лента с видимыми постами.
- Основной поток:
  1. Пользователь нажимает на тело поста (область вне интерактивных элементов).
  2. Система переходит по адресу `/<username>/status/<id>`.
  3. Система показывает текст поста, медиа, метаданные автора и счетчики реакций.
  4. Система показывает блок ответов и поле `Post your reply`.
- Постусловие: пользователь находится на странице поста и может читать ответы или отвечать.

## UC-11. Лайк и снятие лайка

- Актор: `Авторизованный пользователь`
- Предусловие: открыт пост или лента с постами.
- Основной поток:
  1. Пользователь нажимает кнопку `Like` (иконка сердца) на посте.
  2. Система меняет состояние кнопки на `Liked`, иконка становится заполненной.
  3. Система увеличивает счетчик лайков на 1.
  4. Пользователь повторно нажимает на ту же кнопку.
  5. Система возвращает состояние `Like`, иконка становится контурной.
  6. Система уменьшает счетчик лайков на 1.
- Постусловие: лайк проставлен или снят, счетчик отражает фактическое состояние.

## UC-12. Поиск по сайту

- Актор: `Авторизованный пользователь`
- Предусловие: пользователь авторизован, видна правая панель с полем `Search`.
- Основной поток:
  1. Пользователь устанавливает фокус на поле `Search`.
  2. Система показывает блок недавних запросов и предложений.
  3. Пользователь вводит поисковый запрос.
  4. Система показывает выпадающий список с подсказками по людям, хэштегам и темам.
  5. Пользователь нажимает `Enter`.
  6. Система открывает страницу `/search?q=<query>` с вкладками `Top`, `Latest`, `People`, `Media`, `Lists`.
  7. Пользователь переключает вкладку `Latest`.
  8. Система показывает релевантные посты, отсортированные по времени.
- Постусловие: пользователь получил список результатов и может перейти к посту, профилю или хэштегу.
